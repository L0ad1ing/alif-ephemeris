# Contributing

Thank you for helping. Questions and bug reports: open an issue or write to info@alifastrology.com.

Rules that keep this project free for everyone:
1. **Clean room.** Do not read, copy or port Swiss Ephemeris code, data files or documentation, and do not paste
   anything derived from them. Read `docs/CLEAN_ROOM.md`. Comparing our numbers with theirs is fine.
2. Use published formulas and public data (NASA/JPL, IAU, IERS, Hipparcos). Say where a formula came from in the
   commit message if it is not obvious.
3. Every change needs a test. `python -m pytest -q` must pass.
4. Plain words in documentation, short sentences, no em-dashes.

By contributing you agree your work is licensed under Apache-2.0, the same as the project.
